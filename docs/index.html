Herramientas IdeaBoard + IdeaSense

Aplicaciones web para trabajar con la IdeaBoard y el IdeaSense Explorer desde el navegador: medir y experimentar, programar con bloques y entrenar modelos de inteligencia artificial. Conecta la tarjeta por USB y abre la herramienta que necesites.

Requisitos: Chrome o Edge en una computadora (Windows, macOS, Linux o ChromeOS) y un cable USB que transmita datos. Usa una sola herramienta a la vez: si una está conectada a la tarjeta, las demás no podrán abrir el puerto.
