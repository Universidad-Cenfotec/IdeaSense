# Ejemplos

Programas cortos en CircuitPython para IdeaBoard + IdeaSense Explorer, ordenados de lo más simple a lo más complejo. Todos se pueden copiar y ejecutar directamente en [IdeaCode](https://ideacode.crcibernetica.com/), sin librerías adicionales.

| Carpeta | Tema | Ejemplos |
| :--- | :--- | :--- |
| [01_matriz_y_botones](01_matriz_y_botones/) | Dibujar en la matriz 5×5 y leer los botones A, B, C | letras, íconos, Tetris |
| [02_sensores_ambientales](02_sensores_ambientales/) | Luz y temperatura | medidor de luz, gráficos de temperatura |
| [03_movimiento](03_movimiento/) | Acelerómetro e inclinación | flechas, gota, nivel de burbuja |
| [04_pines_ideaboard](04_pines_ideaboard/) | Potenciómetro y sensor táctil en los pines de la IdeaBoard | perilla, interfaz táctil, mascota |
| [05_sistemas_y_evolucion](05_sistemas_y_evolucion/) | Cibernética y algoritmos genéticos | máquina de Ashby, algoritmo genético |

Para proyectos de inteligencia artificial, ver [`IdeaAI_Ejemplos`](../IdeaAI_Ejemplos/), [`MultiLayerPerceptron`](../MultiLayerPerceptron/) y [`Techable_Ideasense`](../Techable_Ideasense/).

## Estructura de cada ejemplo

Cada archivo empieza con un encabezado como este:

```python
"""
Nombre del ejemplo
==================

Qué hace el programa.

Hardware : IdeaBoard + IdeaSense Explorer
Controles: cómo se usa
Usa      : partes de la API que aprende el estudiante
Autoría  : nombre — Universidad CENFOTEC
"""
```
